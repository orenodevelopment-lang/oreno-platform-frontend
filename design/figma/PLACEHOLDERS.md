# Placeholder assets

No royalty-free photograph placeholders were required.

The only embedded photograph in the desktop SVG was extracted exactly to
`public/assets/figma/hiring-simplified-crowd.jpg`.

The three showcase media blocks in the desktop SVG are themselves labelled
“Gif Image here / the white should be transparent.” The source does not provide
those GIFs. After product-owner approval, the labelled placeholders were
replaced with lightweight, code-native product narratives for candidate
curation, selection/interviewing, and onboarding. They use the Oreno palette
and existing motion system without claiming to be Figma-exported artwork.
