# Oreno Platform Frontend

Frontend repository for the Oreno public website and, later, the wider Oreno platform.

## Current scope

The first implementation target is the public marketing website shown in Figma. Dashboard, hiring workspace, talent workspace, authentication, and other platform screens are outside this first website build.
