# Placeholder assets

No royalty-free photograph placeholders were required.

The only embedded photograph in the desktop SVG was extracted exactly to
`public/assets/figma/hiring-simplified-crowd.jpg`.

The three showcase media blocks in the desktop SVG are themselves labelled
“Gif Image here / the white should be transparent.” Because the source design
does not provide those GIFs or depict photographs that could be matched
faithfully, the implementation preserves those labelled media blocks instead
of inventing unrelated photographic content.
